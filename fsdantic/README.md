# Fsdantic

Type-safe Pydantic interface for AgentFS SDK.

Fsdantic provides a clean, structured wrapper around AgentFS functionality with strong typing and validation.

## Features

- Type-safe filesystem operations with Pydantic models
- Powerful query interface for searching files
- Generic repository pattern for KV store operations
- Overlay filesystem management and merging
- Virtual-to-physical filesystem materialization
- Comprehensive exception handling

## Installation

```bash
pip install fsdantic
```
